# Equip Micalet GNU/Linux

Hola! Som l'equip darrere de Micalet GNU/Linux, la distro independent valenciana, basada en Ubuntu.
 Ara mateix treballem en les primeres versions Beta, però estimem que per a març de 2027
 tindrem la nostra primera versió estable!

A aquesta pàgina de GitHub tens disponibles tots els repositoris relacionats amb la nostra distribució.
Els paquets ja construits els pots trobar a la nostra pàgina de Launchpad:
https://launchpad.net/~micalet-dev/
